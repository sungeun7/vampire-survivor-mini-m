# 뱀파이어 서바이버 미니 (모바일 버전)

뱀파이어 서바이버 스타일의 미니 **모바일** 생존 게임입니다.
상위 폴더의 [vampire-survivor-mini](../vampire-survivor-mini)(PC·키보드·Tailscale 멀티플레이)의 **모바일/터치 전용 버전**입니다.

## 플레이 방법

- **이동**: 왼쪽 하단 조이스틱을 드래그하여 캐릭터 이동
- **공격**: 자동으로 주기적으로 투사체 발사 (조작 불필요)
- **경험치**: 적을 처치하면 노란 보석(젬)이 떨어짐. 가까이 가면 자석처럼 끌려와 수집
- **레벨업**: 경험치가 차면 레벨업 → 3가지 업그레이드 중 하나 선택

## 실행 방법 (가장 간단)

1) 폴더에서 `index.html`을 더블클릭해서 브라우저로 열기

> 일부 브라우저/환경에서는 로컬 파일 실행이 제한될 수 있어요. 그럴 땐 아래 "로컬 서버" 방식으로 실행하세요.

## 실행 방법 (로컬 서버)

PowerShell에서 프로젝트 폴더로 이동 후:

```powershell
python -m http.server 5173
```

그 다음 브라우저에서 `http://localhost:5173` 접속.
모바일에서 플레이하려면 같은 Wi‑Fi에서 PC에 서버를 띄운 뒤, 휴대폰 브라우저로 `http://<PC IP>:5173` 접속하세요.

## 파일 구성

- `index.html` - 게임 페이지
- `css/style.css` - 스타일·UI
- `js/game.js` - 게임 로직 (플레이어, 적, 투사체, 경험치, 레벨업)
- `manifest.json` - PWA 앱 매니페스트 (홈 화면에 추가 시 사용)

## 업그레이드 종류

- 공격력 +30%
- 이동속도 +15%
- 사거리 +20%
- 공격속도 +15%
- 투사체 +1
- 자석 범위 +25%
- 최대 체력 +20
- 체력 재생 (초당 1)
